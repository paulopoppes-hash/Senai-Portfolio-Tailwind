# Senai-Portfolio-Tailwind

Portfolio de Projetos — Tailwind CSS

## Descrição

Página de portfolio desenvolvida com HTML e Tailwind CSS, aplicando pelo menos 30 classes utilitárias diferentes (cores, tipografia, espaçamentos, dimensões, bordas, posicionamento, flexbox, grid e responsividade) conforme proposto na Aula 07.

## Tecnologias

- HTML5
- Tailwind CSS (via CDN)

## Classes utilitárias aplicadas (30+)

Layout: flex, flex-col, grid, grid-cols-1, md:grid-cols-2, lg:grid-cols-3, gap-4, gap-8, items-center, justify-center, justify-between
Espaçamento: p-4, p-6, py-16, px-4, mb-4, mt-8, mt-16, mx-auto
Dimensões: w-16, h-16, max-w-6xl, max-w-2xl
Cores: bg-white, bg-gray-50, bg-indigo-900, bg-indigo-100, bg-green-100, text-white, text-gray-900, text-gray-600, text-indigo-600
Bordas: rounded-xl, rounded-lg, rounded-full, border, border-gray-100, border-gray-200, border-t
Tipografia: text-5xl, text-3xl, text-xl, text-lg, text-sm, font-bold, font-semibold, font-medium
Posicionamento: sticky, top-0, z-50, absolute (não usado), relative (não usado)
Responsividade: md:, lg: prefixos para adaptar a diferentes telas

## Como executar

Abra o arquivo `index.html` em qualquer navegador moderno (requer conexão com a internet para carregar o Tailwind via CDN).
